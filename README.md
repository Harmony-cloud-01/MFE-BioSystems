# MFE-BioSystems

Supporting materials for:

**Magnetic-Field Confinement Regularisation for Biomedical Electromagnetic Systems**

Paul D. Markov  
*Journal of Computer Science and Engineering Research (JCSER)*, Volume 3, Issue 1, pp. 31–37, 2026.  
DOI: [10.64820/AEPJCSER.31.31.37.62026](https://doi.org/10.64820/AEPJCSER.31.31.37.62026)

## Repository purpose

This repository is the public code location for the paper's simplified Python toy models and figure/table post-processing materials.

The article's published Data and Code Availability section printed an incorrect GitHub organisation:

`https://github.com/Harmony-Research/MFE-BioSystems`

The correct, author-controlled repository is:

`https://github.com/Harmony-cloud-01/MFE-BioSystems`

## Availability

The publication distinguishes between two sets of materials:

- **Public repository materials:** simplified Python scripts for the illustrative toy models and post-processing scripts for figures and tables.
- **Available from the corresponding author upon reasonable request:** full COMSOL Multiphysics 6.2 model files and the FEniCSx implementations used for independent verification.

The supporting scripts are being assembled here from the publication archive. Until that upload is complete, please contact the author for the materials described in the paper.

## Scientific scope

The paper studies a phenomenological resonance-confinement regularisation for passive magnetic-field shaping in heterogeneous, lossy biomedical media. It reports finite-element evaluations for MRI-inspired and prosthetic-interface configurations and uses a normalised resonance-overlap metric to compare designed and realised magnetic-energy distributions.

The work is computational. It does not report clinical testing, physical phantom validation, or a medical device implementation.
